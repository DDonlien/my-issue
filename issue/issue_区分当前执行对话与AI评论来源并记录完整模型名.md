# Description

## 当前需求与范围

- [ ] [CODEX-PLUGIN-CONVERSATION-002] 对话分为当前执行 Issue 的单个“当前对话”和每条 AI 评论自己的来源对话。详情侧栏及卡片显示当前对话；评论旁提供直接跳转和显式关联入口。切换当前对话不得改变历史评论的来源，新增评论不得默认继承当前对话。地址必须来自可信宿主上下文或用户显式选择，不从匿名 session 或最近聊天猜测。
- [ ] [CODEX-PLUGIN-COMMENT-MODEL-001] 新 AI 评论记录实际完整模型标识，例如 gpt-6-sol、gpt-6-luna 或 gpt-6.1-sol；不把 gpt-6 等家族名当作具体版本。不可获得时使用 unknown 并在结果中说明。旧评论仅在原写入对话和时间记录证明具体模型时，通过关联元数据的可选 model 字段显式校正显示；标题和正文不改写，不能猜测缺失版本。

兼容与失败行为：新增可选普通 YAML 属性 `current_conversation: {url, title}` 和 `comment_conversations: {评论ID: {url, title}}`。评论 ID 由不可变的标题与正文派生，同内容重复项使用稳定的出现序号；不写入新的正文协议章节。旧 `conversations` 数组原文保留，仅有一个有效关联且未显式设置当前对话时兼容显示；多个旧关联不猜测当前目标。旧评论可通过新增关联属性补上来源；经过原写入记录核实的具体模型可存为可选 model 校正，标题和正文不改写。保存来源与追加评论可在同一次 revision/锁检查内完成；过期版本、未知评论 ID、冲突的 Schema 映射或不可解析的关联属性均拒绝写入并保留原文件。普通 YAML 编辑仍可维护或移除这些可选关联。
