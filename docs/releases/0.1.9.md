# myIssue 0.1.9

将 Issue 名称、描述、属性和评论保存在项目内的 Markdown 文件，通过看板与 Codex 对话共同维护。此版本使用本机 MCP 服务，适合已支持本地插件的 Codex 桌面端和 CLI。

## 功能

- 看板和列表、搜索、状态筛选与可开始视图；编辑 Issue 和任意 YAML 属性。
- 项目文件是唯一事实来源；评论只追加，更新检查 revision，发生冲突时保留当前文件。
- 同一电脑的面板共享项目列表，顶部菜单添加和切换项目。
- 跟随宿主浅色/深色，使用 shadcn/ui 控件；长名称换行，评论输入固定在详情底部。
- 图片和文本附件在描述及评论的引用位置直接预览，其他附件可下载。
- 从对话创建、读取和更新 Issue；分发入口显示真实 Codex 对话名称，并按宿主发送能力启用。

## 安装

需要 Node.js 22+；已验证的 CLI 基线为 Codex 0.159.2。

```sh
git clone https://github.com/DDonlien/my-issue.git
cd my-issue
npm ci
npm run install:plugin
```

安装后完全退出并重开 ChatGPT / Codex 桌面应用，再打开 myIssue。已有会话可能保留旧版 MCP 进程，仅关闭插件页面不一定刷新运行版本。

ZIP 已包含运行所需代码，解压后是完整插件根目录，可由兼容 Marketplace 分发；使用者不需要在插件目录安装 npm 依赖。校验下载文件：

```sh
shasum -a 256 -c SHA256SUMS
```

## 当前边界

- GitHub 安装版发布不等同于进入 ChatGPT / Codex 公共插件目录。
- 全局入口、右侧对话、系统输入框及额外顶栏由宿主管理。
- 当前/新对话发送依赖宿主消息接口；已有对话的定向发送需要宿主开放控制接口。接口缺失时禁用发送。
- 新版原生桌面入口、真实定向发送和用户自定义重点色仍需独立验收；自动测试或 SDK 测试宿主不替代这些结果。
- 单个附件上限 10 MB，自动文本预览上限 64 KiB；SVG/HTML 等内容不执行。
- 当前系统文件夹浏览在 macOS 实现，其他系统使用手动路径。

正式发布前需补齐项目许可证。第三方许可随包位于 `THIRD_PARTY_NOTICES.txt`。
