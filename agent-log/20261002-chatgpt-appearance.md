# 执行日志：ChatGPT 外观与宿主主题

## 用户请求

“这个界面应该和 CHATGPT 一样；另外配色也是，希望继承 chatgpt 的配色逻辑，可能的话甚至继承自定义的重点色”。两张截图分别展示旧版 myIssue 紫色项目选择窗和 ChatGPT 中性炭灰项目弹窗、橙色焦点。

## 决策与改动

- 先记录 CODEX-PLUGIN-010。沿用项目选择、名称、属性与评论语义，不引入创建 ChatGPT 项目或账号流程。
- 原实现虽然应用宿主变量，CSS 仍固定紫色和偏蓝的暗色。改为消费标准 MCP Apps 背景、文字、边框、焦点、字体、圆角与阴影变量，中性默认值兼容未提供变量的宿主。
- 使用 light-dark()，宿主明确的 data-theme / color-scheme 优先于系统偏好。监听 SDK 完整合并后的上下文；清除已撤回或空的变量，避免重点色与旧主题残留。
- 项目弹窗使用圆角、文件夹图标输入框、可用项目列表、中性信息区与胶囊按钮；创建窗共用弹窗键盘行为。Tab 限定在弹窗中，Escape 关闭后还原焦点，背景 inert；弹窗期间暂停自动刷新，避免覆盖正在输入的文件夹路径。
- 按钮默认黑/白反色，输入焦点继承 color-ring-primary，链接继承 color-text-info。协议没有专门的用户重点色设置字段，实际同步取决于宿主提供的变量。截图橙色只用于隔离验证，不硬编码到产品。
- 插件升级 0.1.1，资源 URI 升级 board-v2.html，更新中性图标与清单品牌色。未更改 Markdown 解析、写入、Schema 或分发逻辑。
