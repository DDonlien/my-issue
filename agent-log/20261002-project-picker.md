# 执行日志：文件夹选择、桌面项目与弹窗背景

## 原始请求

“下面的部分点不了无法打开文件夹；另外这里应该能获取到 chatgpt app 已经添加的项目会比较好；这个 popup 的背景透明不需要”。用户截图显示项目选择窗下方灰色说明区域无法选择目录，且底层欢迎页面透过弹窗背景。

## 决策

- 先记录 CODEX-PLUGIN-012，保留名称、属性、评论的现有语义与 Markdown 唯一事实来源，不改 Schema 或文件核心。
- 原灰色区域只是说明，没有点击处理器。替换为明确的“浏览文件夹”按钮；选中目录只填入路径，点击“打开项目”才切换。macOS 使用固定 AppleScript 的系统目录选择器，不把文件夹上传至页面，不插入用户输入到脚本。
- 使用公开 Codex app-server JSON-RPC 的 project/list 读取桌面登记的本地项目，不读取桌面私有配置文件。保留项目名称，只使用主要根目录；额外工作空间根目录可能是共享依赖或附件，不作为独立项目展示。无本地目录的云项目不参与文件看板。
- 每次打开弹窗刷新项目列表；后台读取有截止时间、响应与分页上限，失败保留手动路径、宿主共享目录及最近已打开项目。发现项目不自动选中，也不写入 Issue。
- 宿主语义颜色可能包含透明度。弹窗以不透明浅色/深色底色承接宿主颜色，保留主题和焦点色。

## 改动

- src/web/app.tsx、bridge.ts、style.css：真正可点击的浏览区域、打开弹窗刷新已添加项目、取消保留输入、弹窗内错误提示、等待成功后切换项目、不透明弹窗底色。
- src/preview.ts：浏览器预览复用相同桌面适配，只在读取项目列表或看板时查询项目。
