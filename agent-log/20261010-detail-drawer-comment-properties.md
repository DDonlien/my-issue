# 执行日志：详情抽屉、评论顺序与属性直编

## 原始请求

- 宽屏打开 Issue 时保留看板，并从右侧打开详情抽屉；宽度不足时详情独占页面。
- 精简右侧分发入口；评论输入移至评论流顶部，最新评论置顶。
- 描述区不放“添加附件”按钮，新建和详情页均可拖入文件。
- 详情属性不使用统一编辑开关；有权限时每项默认可编辑，可单独保存和调整。
- 确认当前显示版本是否过期，并打包最新版本。

## 决策

- 抽屉断点设为 960px；窄于此宽度详情全屏，宽屏看板留在背景并可通过返回或点击遮罩关闭详情。
- 评论输入成为评论滚动内容的一部分，显示在最新评论之前；保留追加式评论协议。
- 描述拖放支持普通文件、图片和视频。编辑器使用当前光标位置，预览时添加到描述末尾；附件沿用现有项目路径安全检查和 10 MB 上限。
- 属性输入直接显示在各属性行，每个属性独立保存/删除；YAML 值解析保留文本、数字、布尔、数组、对象及空值。
