# shadcn/ui components

These components come from the official [shadcn/ui registry](https://ui.shadcn.com/r/styles/new-york-v4/button.json), retrieved on 2026-10-07. Each component uses the registry URL with its own filename. Internal component imports are adjusted to local `.js` paths for this TypeScript project.

Keep the standard component behavior and variants. Product layouts belong outside this directory; ChatGPT host colors are mapped to shadcn semantic tokens in `src/web/style.css`. `components.json` records the registry/style configuration. Bundled dependencies and their license text are included in the plugin's third-party notices.
